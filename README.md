# 💻 Kayo Julian — Portfólio de Desenvolvimento Web - https://kayolindo58.github.io/site-de-kayo/

Portfólio pessoal desenvolvido para apresentar minhas habilidades, meus conhecimentos em desenvolvimento web e meus canais de contato profissional.

O projeto foi criado com **HTML, CSS e JavaScript**, utilizando um design escuro, detalhes em roxo e uma interface adaptada para diferentes tamanhos de tela.

## ✨ Sobre o projeto

O site funciona como uma apresentação profissional, reunindo informações sobre mim, as tecnologias com as quais trabalho e os serviços relacionados ao desenvolvimento web.

A proposta é oferecer uma forma simples e visual de conhecer meu trabalho e acessar meus perfis profissionais.

## 🚀 Funcionalidades

- **Página inicial:** apresentação pessoal e identificação como desenvolvedor web.
- **Seção Sobre mim:** informações sobre minha atuação e meus conhecimentos.
- **Cards de serviços:** apresentação das áreas de Front-end, Back-end e desenvolvimento de sistemas e sites.
- **Navegação por seções:** links para Início, Sobre e Contato.
- **Menu dinâmico:** destaque da seção ativa conforme a navegação pela página.
- **Redes sociais:** atalhos para GitHub, LinkedIn, Instagram e Discord.
- **Contato via WhatsApp:** acesso direto ao canal de contato.
- **Layout responsivo:** ajustes de espaçamento e organização para telas menores.
- **Identidade visual personalizada:** tema escuro com elementos em roxo e imagens próprias.

### Principais arquivos

- **`index.html`:** contém a estrutura do portfólio, as seções de apresentação, os cards de serviços e os links de contato.
- **`style.css`:** define o tema visual, a tipografia, os botões, os cards e as adaptações para dispositivos móveis.
- **`arquivo.js`:** identifica a seção visível durante a rolagem da página e atualiza o destaque do menu.
- **`assets/`:** reúne as imagens, o logotipo, o plano de fundo e os ícones utilizados no site.

## ▶️ Como executar

Não é necessário instalar dependências ou configurar um banco de dados.

1. Faça o download ou clone o repositório.
2. Abra a pasta `html`.
3. Abra o arquivo `index.html` no navegador.

Para desenvolver e testar o projeto, você também pode abrir a pasta no Visual Studio Code e utilizar a extensão Live Server.
